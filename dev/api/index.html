DDMFaultSlip.DDMesh1D — Type
DDMesh1D(start_point::SVector{2,T}, end_point::SVector{2,T}, n::Int)

One-dimensional mesh of n uniform edge elements between start_point and end_point. It discretizes a fault or fracture in a 2D medium (plane strain), or the radial profile of a penny-shaped crack for axisymmetric problems.

Example

mesh = DDMesh1D(SVector(-1.0, 0.0), SVector(1.0, 0.0), 100)
source
DDMFaultSlip.DDMesh2D — Type
DDMesh2D(T::DataType, file::String; log::Bool=false)

Two-dimensional triangular mesh of a planar fault or fracture in a 3D medium, read from a Gmsh mesh file in format 4.1 (gmsh -2 mesh.geo -o mesh.msh). The mesh must lie in the $z = 0$ plane.

Note

file is resolved relative to the directory of the calling script.

Example

mesh = DDMesh2D(Float64, "mesh.msh")
source

Problems

DDMFaultSlip.NormalDDProblem — Type
NormalDDProblem(mesh::DDMesh{T}; μ=1.0, ν=0.0, axisymmetric=false, transient=false)

Opening (mode I) problem solving for the normal displacement discontinuity w (field problem.w) and the normal stress σ (field problem.σ) of the elements of mesh. μ is the shear modulus and ν the Poisson's ratio of the medium. With a DDMesh1D, axisymmetric=true treats the mesh as the radial profile of a penny-shaped crack.

source
DDMFaultSlip.ShearDDProblem — Type
ShearDDProblem(mesh::DDMesh{T}; μ=1.0, ν=0.0, axisymmetric=false, transient=false)

Shear (fault slip) problem solving for the shear displacement discontinuity (slip) δ (field problem.δ), the shear stress τ (field problem.τ) and the normal stress σ (field problem.σ) of the elements of mesh. μ is the shear modulus and ν the Poisson's ratio of the medium.

  • With a DDMesh1D, the problem is a 2D plane strain problem, or a 3D axisymmetric problem on the radial profile of the fault if axisymmetric=true.
  • With a DDMesh2D and ν = 0, the two slip components decouple and a single slip component (aligned with the shear stress) is solved for.
  • With a DDMesh2D and ν ≠ 0, the two slip components are solved for: values are stored as [x-components; y-components], and initial conditions and constraints take a direction :x or :y.
source

Constraints

DDMFaultSlip.addConstraint! — Function
addConstraint!(problem, cst::AbstractConstraint[, dir::Symbol])

Add a constraint (e.g. a FunctionConstraint) to problem. For a 3D ShearDDProblem with $ν ≠ 0$, dir (:x or :y) gives the slip component the constraint applies to.

source
DDMFaultSlip.FunctionConstraint — Type
FunctionConstraint(func_res::Function[, func_jac::Function])

Constraint imposing a stress change on each element through the function func_res(X, Δu), where X is the element centroid and Δu the increment of displacement discontinuity of the element. The optional func_jac(X, Δu) returns the derivative of func_res with respect to Δu (zero by default).

Example

# Uniform tensile stress (stresses are positive in compression)
addConstraint!(problem, FunctionConstraint((X, Δw) -> -1.0))
source
DDMFaultSlip.addFrictionConstraint! — Function
addFrictionConstraint!(problem, friction::AbstractFriction)

Add a frictional constraint (ConstantFriction, SlipWeakeningFriction or ConstantYield) to problem. A problem can have only one frictional constraint.

source
DDMFaultSlip.ConstantFriction — Type
ConstantFriction(f::T, k::T; η=0.0, abs_tol=1.0e-12, rel_tol=1.0e-10, max_iter=20)

Coulomb frictional constraint with constant friction coefficient f: slip occurs where the shear stress reaches $f σ'$, with $σ'$ the effective normal stress.

The fault is modelled as an elasto-(visco)plastic interface of shear stiffness k (typically $μ/h$ with $h$ the fault thickness, large enough to act as a penalty): $τ = τ_{old} + k (Δδ - Δδ^p)$ and the yield condition $τ - f σ' - η Δδ^p / Δt ≤ 0$ with η an optional viscosity regularizing the slip. abs_tol, rel_tol and max_iter control the local return-map iterations.

Example

addFrictionConstraint!(problem, ConstantFriction(0.6, μ / 1.0e-05))
source
DDMFaultSlip.SlipWeakeningFriction — Type
SlipWeakeningFriction(fₚ::T, fᵣ::T, δᵣ::T, k::T; η=0.0, abs_tol=1.0e-12, rel_tol=1.0e-10, max_iter=20)

Frictional constraint with a linear slip-weakening friction coefficient: the friction coefficient decreases from its peak value fₚ to its residual value fᵣ over the slip δᵣ, and remains equal to fᵣ afterwards. See ConstantFriction for the other arguments.

source
DDMFaultSlip.ConstantYield — Type
ConstantYield(τ₀::T, k::T; η=0.0, abs_tol=1.0e-12, rel_tol=1.0e-10, max_iter=20)

Frictional constraint with a constant shear strength τ₀, independent of the normal stress. k is the elastic shear stiffness of the fault (typically $μ/h$ with $h$ the fault thickness). See ConstantFriction for the other arguments.

source

source
DDMFaultSlip.DugdaleCohesiveZone — Type
DugdaleCohesiveZone(σₚ::T, σᵣ::T, l::T, k::T; abs_tol=1.0e-12, rel_tol=1.0e-10, max_iter=20)

Dugdale cohesive zone constraint for opening problems (NormalDDProblem): inelastic opening develops when the normal stress reaches the residual strength σᵣ within a distance l of the origin (the open crack), and the peak strength σₚ elsewhere. k is the elastic normal stiffness of the interface (typically $μ/h$).

Fluid coupling

DDMFaultSlip.addFluidCoupling! — Function
addFluidCoupling!(problem, pp::AbstractFluidCoupling)

Couple problem to a pore fluid pressure (e.g. FunctionPressure). A problem can have only one fluid coupling.

source
DDMFaultSlip.FunctionPressure — Type
FunctionPressure(mesh::DDMesh{T}, fct::Function; fct_ic::Function=default_fc_ic)

Fluid coupling with a pore pressure prescribed by the function fct(X, time), which returns the vector of pressures at the element centroids X at time time. The change of pressure reduces the effective normal stress acting on the fault ($σ' = σ - p$). fct_ic(X) gives the initial pressure (zero by default).

Example

# Pressure diffusing from a line source at x = 0
pressure(X, t) = Δp * erfc.([abs(x[1]) for x in X] / sqrt(α * t))
addFluidCoupling!(problem, FunctionPressure(mesh, pressure))
source

Time stepping

DDMFaultSlip.ConstantDT — Type
ConstantDT(start_time::T, end_time::T, n::Int; growth_factor=2.0, cutback_factor=0.5, tol=1.0e-08)

Time stepper with a constant time step size dt = (end_time - start_time) / n. After a time step was cut back, the time step size grows again by growth_factor until it reaches dt.

source
DDMFaultSlip.TimeSequence — Type
TimeSequence(time_seq::Vector{T}; start_time=time_seq[1], end_time=time_seq[end], cutback_factor=0.5, tol=1.0e-08)

Time stepper following the sorted sequence of times time_seq. A start time of 0 is prepended to the sequence if missing, and end_time is appended if it is larger than the last time of the sequence.

Example

# 100 logarithmically spaced time steps between 1e-3 and 1
time_stepper = TimeSequence(exp10.(range(-3, 0, length=100)); start_time=0.0)

VTKDomainOutput(mesh::DDMesh2D, filename::String)

Output of the element values of a 3D problem to VTK files (filename_<step>.vtu, gathered in filename.pvd) for visualization with e.g. ParaView. Relative paths are resolved from the directory of the calling script; missing directories are created.

source
DDMFaultSlip.CSVDomainOutput — Type
CSVDomainOutput(mesh::DDMesh1D, filename::String)

Output of the element values of a 2D problem to one CSV file per time step (filename_<step>.csv). Columns are the element centroid coordinates x,y followed by the problem variables (e.g. sigma,delta,delta_dot,tau,p for a ShearDDProblem with fluid coupling). Relative paths are resolved from the directory of the calling script; missing directories are created.

CSVMaximumOutput(filename::String)

Output of the maximum values of the problem variables over the mesh, one line per time step, to the CSV file filename.csv. Relative paths are resolved from the directory of the calling script; missing directories are created.

Running simulations

DDMFaultSlip.run! — Function
run!(problem; kwargs...)

Solve the steady-state (single load step) problem. See the transient method below for the keyword arguments.

source
run!(problem, time_stepper; kwargs...)

Solve the transient problem over the time steps given by time_stepper (ConstantDT or TimeSequence). Failed time steps are retried with half the time step size.

Keyword arguments

  • outputs::Vector{<:AbstractOutput}: outputs executed after each time step.
  • output_initial=false: also execute the outputs for the initial state.
  • log=true: print simulation information and nonlinear residuals.
  • linear_log=false: print linear solver information.
  • nl_max_it=100, nl_abs_tol=1.0e-10, nl_rel_tol=1.0e-10: maximum number of iterations and tolerances of the Newton solver.
  • l_solver="idrs": linear solver ("idrs", "gmres" or "bicgstabl").
  • l_max_it=1000, l_abs_tol=1.0e-10, l_rel_tol=1.0e-10: maximum number of iterations and tolerances of the linear solver.
  • pc=true: use a hierarchical LU preconditioner.
  • pc_atol=1.0e-01: compression tolerance of the hierarchical LU preconditioner.
  • pc_refresh_it=10: recompute the preconditioner when the last linear solve needed more iterations than this.
  • pc_lin_rtol=1.0e-06: recompute the preconditioner when the true relative residual of the last linear solve is above this tolerance.
  • hmat_eta=2.0, hmat_atol=1.0e-06: admissibility parameter and compression tolerance of the hierarchical elastic matrix.
  • dt_min=1.0e-14: the simulation fails if the time step is cut below this value.
source
DDMFaultSlip.DDSolver — Type
DDSolver

Nonlinear solver of a DD problem, created by run!. The elastic collocation matrix is assembled once as a hierarchical matrix, and the nonlinear system is solved with Newton iterations, using a preconditioned Krylov method for the linear systems.

source
